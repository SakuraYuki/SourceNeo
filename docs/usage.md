# 使用指南

## 界面与外观

工具栏以图标呈现克隆、导入、抓取、搜索、比较、分组和导出等次要操作，悬停显示名称；同步等主操作保留图标和文字。导航页签、当前分支及确认 / 取消按钮保留文字。停止排队、取消克隆、删除分组和移除仓库使用贴近入口的轻量确认，说明操作影响；默认聚焦“取消”，支持 Escape 和点击外部取消。停止类操作使用警示色，删除 / 移除使用危险色，确认前不执行操作。

状态提示中的“查看处理建议 / 查看未提交文件”保留图标和文字，与“同步此仓库”靠右排列。顶部 抓取 全部位于“同步全部”左侧，抓取 入口统一使用云端获取图标；同步规则由底部文字说明，不再显示“安全同步”标签。顶部移除重复的应用标识和“仓库总览”，将已同步 / 需关注和任务结果并入左侧，操作集中在右侧；仓库总数保留在本地仓库标题和同步全部按钮中。提交历史按本地时区显示完整提交时间，格式为 `YYYY-MM-DD HH:mm:ss`。

每个仓库仅占一行，显示仓库名、分支与同步状态；悬停仓库名或该行可查看完整路径。宽窗口默认左右布局，分隔栏可拖动，也支持左右方向键调整。右上角布局按钮可切换左右 / 上下布局；窗口窄于 1040px 时自动使用上下布局，加宽后恢复所选布局。

左右布局采用紧凑侧栏，宽度可在 260–560px 范围调整，隐藏表头，优先给仓库名留空间，分支与状态按内容占位；窄于 300px 时隐藏分支文字，完整分支仍可在行的悬停提示中查看。同步和“⋯”按钮在悬停、键盘聚焦或操作进行中显示。上下布局保留表格列。

仓库行支持右键菜单，也可通过行内“⋯”或聚焦后按 Shift+F10 / 菜单键打开。菜单提供 抓取、远端选择、同步、分支切换、未提交文件 / 处理建议、终端 / 编辑器打开、复制路径 / 诊断、工具设置及移除。菜单操作始终针对标题标明的仓库，右键其他仓库不切换当前历史；移除仍需确认。详情区保留 抓取、同步、问题查看和当前分支入口，其余操作通过“⋯”打开。菜单支持方向键、Home / End、Enter、Esc，点击外部、滚动外部区域、窗口缩放或失焦时关闭，并在 Esc 后恢复入口焦点。文件与提交继续单击查看。

列表工具栏的“管理仓库分组”可创建、重命名或删除分组。每个仓库归属一个分组，未归组的仓库显示在“未分组”；分组可以折叠。通过仓库菜单的“移动到分组…”或多选后的“移动分组”调整归属。分组和归属与仓库列表一同保存到 `repositories.json`，旧版配置自动按未分组读取；删除分组只将其中仓库恢复为未分组。

仓库右键或“⋯”菜单提供“置顶仓库 / 取消置顶”：置顶后在原组内排在普通仓库前面，并在列表顶部自动生成的“置顶”分组中展示。原有分组归属和普通排序不变，取消置顶后恢复原位置。自动分组可折叠，也参与搜索和筛选；最后一个置顶取消后自动消失，无须在分组管理中维护。两处展示共用状态与勾选，批量操作及计数按仓库去重。

同一菜单的“禁止同步（仍可抓取）/ 允许同步”控制 SourceNeo 内的同步权限。禁止后显示锁定标识，单仓库按钮、仓库菜单、同步预览、同步所选、同步全部和失败重试都不能执行该仓库的同步；批量报告明确显示跳过原因。仍可抓取、刷新、查看历史和差异。执行层在获得仓库操作锁后再次读取标记，避免旧界面或已排队请求绕过。仓库操作或标记保存期间不能重复修改标记；保存失败保持原状态。两个标记随仓库配置原子保存并在重启后保留，旧配置默认未置顶且允许同步。

勾选仓库行左侧复选框进行多选，不改变当前查看的仓库历史；分组复选框选择该分组中符合搜索和筛选条件的仓库。“全选当前可见仓库”只选择已展开且符合筛选条件的仓库，筛选或折叠后保留原有选择，并提示隐藏的已选数量；“清空选择”取消全部勾选。选择后可执行“同步所选”“抓取 所选”或“移动分组”。顶部“同步全部 / 抓取 全部”始终操作完整仓库列表。批量操作显示进度及各仓库的成功、需处理、失败或跳过结果；已在操作的仓库跳过，单个仓库失败不影响其他仓库。最多并行 3 个仓库，排队中的仓库也会标记为操作中，沿用单仓库的同步规则与共享 Git 目录串行规则。

点击仓库行后按空格可切换该行的勾选状态，长按不重复切换；键盘聚焦仓库行时也可使用。普通点击仓库行或切换单个复选框会设置范围起点；按住 Shift 点击另一行的复选框、仓库行，或聚焦另一行后按 Shift+空格，可连续勾选两者之间的仓库。若终点已勾选则取消该范围的勾选，连续 Shift 操作保留原起点。范围以当前显示顺序为准，跳过折叠或筛选后隐藏的行，并保留范围外的原有选择；起点已隐藏或移除时只切换当前行。分组全选、全选可见仓库和清空选择会重置范围起点。

右上角太阳 / 月亮按钮切换浅色和深色模式，覆盖页面、原生窗口、提交图、状态与弹窗。首次启动采用系统明暗外观，此后记住所选模式。主题、布局和左侧仓库列表宽度保存在本机 WebView 存储中，重启后恢复；窗口变窄时临时限制显示宽度，加宽后恢复记住的宽度。

窗口大小、位置及最大化 / 全屏状态在正常退出时保存，重新打开时恢复。窗口状态保存在应用配置目录下的 `.window-state.json`，由 [Tauri Window State](https://v2.tauri.app/plugin/window-state/) 管理。

## 功能概览

- 添加、移除和持久化多个本地仓库；添加子目录会归一为工作区根路径，重复路径不会重复添加；识别 linked worktree。
- 当前分支、未提交文件数、ahead / behind、最后一次成功 fetch 时间。已同步只表示与**已知的远程跟踪引用**一致；本地刷新不会联网。
- 区分已同步、待推送、待拉取、已分叉、已有冲突、需要处理及失败；失败进一步区分网络、认证和其他错误。
- 仓库分组、折叠、搜索、筛选和多选；支持单仓库、全部或所选仓库的同步与 抓取，以及批量移动分组、进度和逐仓库结果；一个仓库失败时其余仓库继续。
- 仓库行直接显示“18 项未提交”“未设上游”“rebase 未完成”“认证失败”等具体原因。顶部“需关注”可打开仓库清单、原因和下一步建议，并定位对应仓库；详情区“查看未提交文件”列出当前路径、修改 / 新增 / 删除 / 重命名，以及已暂存 / 未暂存 / 未跟踪 / 冲突状态。文件清单只读，可手动刷新，不自动提交或丢弃改动。
- Git 真实父子关系驱动的 SVG 提交图，默认只显示当前 HEAD 的历史（含已合并提交）；通过“提交历史”右侧的“全部分支”开关查看全部本地 / 远程分支及其他引用的历史。切换范围后从前 100 条重新加载，每次启动默认关闭。支持 merge、多个根节点、标签及 HEAD；点击提交查看 SHA 与父提交。
- 点击右侧当前分支可切换本地分支、从已有远程引用创建同名跟踪分支，或从当前 HEAD 新建分支。分支列表不自动联网；本地同名分支已存在或被其他 worktree 使用时由 Git 拒绝，不覆盖现有分支。有未提交改动、冲突、未完成操作或 Git 锁时暂停切换，保留被忽略文件，不自动 stash 或强制切换。
- 点击提交后，下方显示新增、修改、删除、重命名文件及逐文件 diff。根提交展示全部新增文件，合并提交与第一父提交比较；二进制文件显示 Git 的差异摘要。读取不执行 external diff / textconv，不读取工作区版本；浅克隆缺少父提交对象时报告读取失败，需要先加深克隆。单文件文本预览最多 2,000 行，超过会明确提示，Git 输出仍受 8 MiB 上限保护。
- 默认加载最近 100 条历史，每次再加载 100 条，最多 5,000 条；虚拟滚动只渲染可见行及相邻缓冲区。浅克隆会提示历史边界。
- 复制路径、分支、状态、冲突文件和相关错误，交给 AI。不会复制 remote URL 配置、凭据配置或文件内容；错误中的 URL 用户信息、常见 token 参数和 Authorization 会脱敏。

## 未提交差异、仅获取远端与外部工具

在“需关注 / 查看未提交文件”中点击文件名，可只读预览。已暂存比较 index 与 HEAD，未暂存比较工作区与 index；同一文件两种状态可切换，首次提交也可查看暂存内容。未跟踪文件显示内容，二进制、空文件、重命名、删除、模式变化和冲突有相应提示。符号链接不读取目标。单文件最多预览 256 KiB / 2,000 行，截断会提示；Git 输出仍受 8 MiB 上限约束，超限报告错误。读取失败可重试，刷新清单、切换文件及关闭后忽略迟到响应。

顶部“抓取 全部”和当前仓库详情区“抓取 此仓库”只获取远程对象与远程跟踪引用。默认使用当前分支配置的命名远端，否则唯一远端可直接获取；多个远端时通过仓库菜单中的“选择获取远端…”选择，没有远端时提示先配置。未设上游、游离 HEAD、空仓库和未提交改动都不阻止已选远端的获取。使用显式 `refs/heads/*:refs/remotes/<remote>/*` 和空 refmap，忽略配置中指向本地分支或标签的 fetch refspec，同时保留经校验、目标位于 `refs/remotes/` 的自定义映射和远端排除规则，保证自定义 upstream 不会停留在旧引用；不 prune、不获取标签或子模块，不 pull / merge / rebase / push。同步的获取阶段复用此策略。共享 Git 目录串行并共用成功时间；全部获取逐仓库处理，一个失败不影响其他仓库，可能重复获取共享目录，以尊重不同 worktree 的分支远端配置。失败保留此前成功时间；详细结果在操作日志中。没有后台联网。

仓库右键菜单和详情区“⋯”菜单提供“在终端打开”“在编辑器打开”和“外部工具设置”。Windows 默认打开可见的 Windows PowerShell，macOS 使用 Terminal；自动检测常见安装位置的 VS Code / Cursor。也可填写终端或编辑器可执行文件的完整路径（Windows 为 `.exe`），留空恢复自动选择，配置与仓库列表一同保存。自定义 PowerShell / pwsh 使用与默认终端一致的安全目录定位；其他自定义终端继承仓库工作目录，编辑器另接收独立的仓库路径参数；程序需支持这些启动约定。缺少程序、启动失败或启动后立即以错误码退出会提示，可配置后重试；外部程序较晚发生的运行错误由其自身处理。不支持任意命令模板，不自动运行 Git 或发送 AI 任务。Windows 默认 PowerShell 用固定脚本和环境变量传递目录，不把路径拼接进脚本；不开放前端 shell 权限。打开位置是当前仓库根目录，包括 linked worktree。

## 刷新、配置和日志

顶部“网络设置”图标可为 HTTP / HTTPS 仓库设置代理，应用于 抓取、同步和克隆。支持 `http://`、`https://`、`socks5://`、`socks5h://` 地址，不支持内嵌账号密码；留空沿用 Git 配置及应用启动时的环境变量。桌面应用通常不继承终端代理，需要在此显式设置，例如 `http://127.0.0.1:12345`。设置单独保存为配置目录中的 `network.json`，从下一次操作起生效；不改写全局 Git 配置，SSH 仓库仍使用自身的 SSH 配置。

使用应用内代理时，可在“直连域名”填写需要绕过代理的域名，多个用逗号分隔，不填协议、端口或仓库路径。例如填写 `.devops.aliyuncs.com`，让 Codeup 仓库直连，同时让 GitHub 继续使用代理。应按实际网络配置分流，避免把原本能直连的仓库统一送入代理。

网络设置提供“沿用 Git 配置”和“手动代理”两种连接方式，切换时保留当前输入；保存沿用模式会清空应用内代理，保留直连规则。直连域名以标签展示，可单独移除，支持回车添加、逗号 / 空格分隔的批量输入及 Codeup 快捷添加。直接保存也会收录输入框中尚未添加的域名，域名自动去重。底部标明未保存的更改，修改从下一次联网操作生效。

- 窗口可见时每 15 秒检查刷新任务，优先处理当前仓库；其他仓库连续无变化时逐步退避至 30 / 60 / 120 秒。回到窗口请求刷新，自动刷新节流为 10 秒；手动刷新节流为 1 秒，并忽略退避刷新全部空闲仓库。
- 远程仅在主动 抓取 或同步时获取；共享 common directory 的 worktree 共用成功 fetch 时间。
- 仓库配置使用同目录临时文件原子替换。macOS 通常为 `~/Library/Application Support/dev.sourceneo.desktop/repositories.json`，Windows 为 `%APPDATA%\dev.sourceneo.desktop\repositories.json`。
- 配置损坏时保留原文件并报告启动错误。移除仓库只移除列表项，不删除仓库。
- 操作日志脱敏后原子写入配置目录的 `operations.json`，最多保留最近 500 条，重启后恢复。日志损坏时保留原文件并显示警告；保存失败时提示当前日志仅在内存中。Git 输出单流上限 8 MiB，错误摘要上限 8 KiB；一般 Git 子进程等待上限 90 秒，克隆上限 15 分钟。
- 调试构建可通过 `SOURCENEO_CONFIG_DIR` 指定隔离配置目录；正式构建忽略此变量。


## 克隆远程仓库与批量导入

顶部“克隆仓库”接受 HTTPS、`ssh://` 或 `git@host:path` 地址。选择父目录并填写新文件夹名称后，执行克隆并自动加入列表。目标目录必须不存在；失败后不自动删除，错误会给出保留位置。进行中可点“取消克隆”，终止本次克隆进程树并保留目标目录；该取消入口不会影响其他同步任务。HTTPS 地址禁止内嵌账号、密码、令牌或查询参数，认证沿用本机 Git 凭据助手 / SSH agent；需要交互认证时先在终端完成。只允许 HTTPS / SSH 传输，不自动克隆子模块。

顶部“批量导入”扫描父目录，深度可选 1–6 层，默认 3 层。跳过 node_modules、target、dist、build、vendor、虚拟环境、缓存和目录链接；识别 `.git` 文件形式的 worktree。找到仓库后不继续扫描其内部。最多检查 10,000 个目录项、收集 500 个仓库，扫描循环设 30 秒预算（正在执行的 Git 子进程仍受自身超时约束），达到上限会提示缩小范围。扫描不修改列表；勾选后才导入。部分失败时成功项保留，仅勾选失败项以便重试。

## 搜索、比较与历史缓存

“搜索提交”按提交说明、作者或 SHA 查询 Git，覆盖尚未在列表加载的历史。说明与作者使用不区分大小写的字面搜索；SHA 支持 4–64 位前缀，必须能唯一解析为提交。SHA 查询不限制当前分支可达性。其他查询可选当前 / 全部分支范围，每页 100 条，最多浏览 5,000 条；过滤结果用列表展示，不伪造连续拓扑。

“比较上游”展示两端独有提交（各最多 100 条）及“上游 → 当前 HEAD”的文件差异；可点击提交或文件查看详情。比较固定两端 SHA，预览不读取工作区内容，不运行 external diff / textconv。浅克隆仅含已有历史；未配置上游会报告错误。

普通历史按固定引用快照增量传输，前端追加计算图布局。快照最多保留 16 个、有效期 10 分钟；普通历史分页遇到失效快照会从新快照重新加载到当前页，搜索快照过期时需重新搜索。超过可传递的引用数量会提示使用当前分支或 SHA 搜索。最近 8 个历史视图缓存 60 秒内可复用，切换仓库恢复分页和滚动位置；已知 HEAD / 分支 / ahead / behind 变化、手动刷新和同步后重新加载。全部分支中的其他引用被外部工具修改时，可手动刷新获得新快照。

## 同步预览与批量任务

仓库菜单或详情区的“同步预览”显示当前分支、远端、上游、生效的 rebase / ff 配置、最后成功 抓取 时间、预计步骤和已知阻塞原因。预览不 抓取、不修改分支，不能保证整合无冲突；实际执行复用原同步流程，重新读取配置与状态，抓取 后再次检查。存在已知阻塞时，可关闭预览处理原因或单独 抓取。

顶部左侧的任务状态入口在批量任务开始时自动展开悬浮报告，显示排队、检查、获取远端、整合、推送阶段，以及运行耗时和结果。面板采用最大约 680 × 660 像素的悬浮布局，并随窗口缩小；标题、进度概览和底部操作固定，仅仓库任务列表滚动。每行展示状态图标、仓库名、结果说明和耗时，不改变仓库列表和提交历史的位置。可手动收起、按 Escape 或点击面板外收起，再点状态入口查看；收起不影响任务。全部成功后 5 秒自动收起，有失败、需处理或跳过项时保留报告。任务入口不使用按钮边框和背景：运行时显示操作与进度，成功后只显示“抓取完成 / 同步完成”，失败、需处理或跳过时显示对应数量；没有任务时不显示入口。“停止排队”需经轻量确认，只跳过尚未开始的任务，让进行中的 Git 操作完成；不会强行中断 merge / rebase。“仅重试失败项”沿用原来的 抓取 / 同步类型，不重复执行成功项；需处理项应解决原因后再手动执行。

## 操作日志

“操作日志”支持当前仓库、指定仓库、全部仓库（含已移除仓库）筛选和关键词搜索。导出 JSON 包含所选仓库的全部保留记录，不受关键词过滤影响。记录含时间、脱敏摘要、阶段和耗时，仍包含本地仓库路径；导出前注意收件范围。所有功能继续遵循手动联网原则。

macOS 原生菜单在启动时按照用户偏好的语言顺序选择中文或英文，保留原生编辑、窗口操作与快捷键；可通过 macOS 的应用语言设置指定，修改语言后重新启动应用。日志仓库筛选、搜索与导出控件统一为 32px 高；应用滚动条采用透明轨道与细圆角滑块，明暗主题下均保留悬停反馈。
